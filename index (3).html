Referencias y recursos

Fuentes para profundizar en el consumo responsable y las herramientas utilizadas en este prototipo:

  • Naciones Unidas — Producción y consumo responsables (ODS 12). Información general sobre el objetivo y sus metas.
  • Naciones Unidas — Agenda 2030 para el Desarrollo Sostenible. Contexto del marco global de sostenibilidad.
  • p5.js — Referencia oficial. Documentación para crear dibujos, animaciones y arte generativo mediante código.
  • GitHub y GitHub Pages. Repositorio de código y publicación del sitio.

Las historias de los objetos son escenarios educativos ilustrativos. Los tiempos de degradación pueden variar según los materiales y las condiciones ambientales.
